# 촬영용 가짜 동영상 앱 요구사항

## 목적
- 스마트폰 영화 촬영에서 실제 동영상 앱처럼 보이는 소품 화면을 제공한다.
- 화면 터치 한 번마다 조회수가 `97 → 98 → 99 → 100`처럼 정확히 1씩 증가해야 한다.

## 필수 기능
- 제공된 썸네일을 16:9 영상 영역에 표시한다.
- 영상은 기본 3초 지점에서 일시정지된 상태이며 빨간 진행률 막대를 표시한다.
- 중앙 재생 버튼은 기본으로 숨기고 설정에서 표시 여부를 바꿀 수 있다.
- 멈춘 시점(초)은 설정에서 수정하며 진행률과 시간 표시에 즉시 반영한다.
- 영상 아래에 제목, 조회수, 업로드 시점, 채널, 액션 버튼, 댓글을 배치한다.
- 화면의 일반 영역을 한 번 터치하거나 키보드 Space/Enter를 누르면 조회수가 1 증가한다.
- 화면 아래 설정 영역에서 시작 조회수를 지정하고 현재 조회수를 해당 값으로 초기화한다.
- 수동 시작 숫자 설정은 유지하며, 바로 아래에 도서관 장면 `45회`와 교실 장면 `97회`로 즉시 초기화하는 두 개의 빠른 버튼을 제공한다.
- 빠른 초기화 버튼은 시작 조회수와 현재 조회수를 함께 변경해 같은 장면을 반복 촬영할 수 있게 한다.
- 모든 설정은 별도 `/settings` 페이지에서 관리한다.
- 촬영 화면 본문에는 설정 버튼이나 설정 안내를 노출하지 않는다.
- 하단 고정 메뉴 맨 오른쪽의 프로필 버튼을 눌렀을 때만 설정 페이지에 진입한다.
- 전체화면 진입/해제를 지원한다.
- 전체화면에서 시스템 표시줄을 숨기는 기본 모드와, 수정 가능한 가짜 상태 표시줄을 보여주는 모드를 모두 제공한다.
- 가짜 상태 표시줄의 시간, 배터리 수치를 수정할 수 있다.
- 댓글별 작성자, 내용, 등장 조회수, 등장 지연 시간을 설정할 수 있다.
- 영상 제목 옆 펼침 버튼으로 모바일식 설명 창을 열고 닫을 수 있다.
- 설명 창에는 영상 제목, 현재 조회수, 업로드 시점, 해시태그를 표시한다.
- 영상 제목과 해시태그는 설정 페이지에서 수정할 수 있다.
- 기본 해시태그의 학교급 표기는 `#중학생`이 아니라 `#초등학생`을 사용한다.
- 좋아요 수와 싫어요 수는 설정 페이지에서 0 이상의 숫자로 수정할 수 있다.
- 설정한 좋아요·싫어요 수는 촬영 화면에 즉시 반영되고, 좋아요 수는 설명 창의 통계에도 동일하게 표시한다.
- 촬영 화면에는 조회수 조작법을 설명하는 안내 문구를 노출하지 않는다.
- 기본 댓글 흐름은 45회 첫 댓글, 100회 두 번째 댓글, 설정된 시간 뒤 마지막 댓글 순서다.

## 촬영 안정성
- 버튼이나 설정 조작은 조회수 증가로 오인되지 않아야 한다.
- 더블탭 확대, 텍스트 선택, 길게 누르기 메뉴를 최대한 억제한다.
- 새로고침 후에도 설정값과 현재 조회수를 같은 기기에서 유지한다.
- 기존 저장 데이터에 좋아요·싫어요 필드가 없어도 기본값을 보완해 정상적으로 불러온다.
- 기존 해시태그가 과거 기본값과 정확히 같으면 `#중학생`을 `#초등학생`으로 자동 전환하되, 사용자가 수정한 해시태그는 보존한다.
- 조회수가 댓글의 등장 기준보다 낮아지면 해당 댓글은 다시 숨겨져 재촬영할 수 있어야 한다.
- 모바일 세로 화면에 우선 최적화하고 태블릿/데스크톱에서는 430px 휴대폰 폭으로 강제 고정해 중앙 정렬한다.
- 빨간 진행률 원 마커는 영상 하단 경계에서 잘리지 않고 전체 원형이 보여야 한다.
- 원 마커가 영상 밖으로 돌출되는 공간만큼 하단 여백을 확보해 다음 콘텐츠와 겹치지 않아야 한다.

## 공개 배포
- GitHub 공개 저장소에서 전체 소스와 변경 이력을 관리한다.
- GitHub Pages에 정적 사이트로 자동 배포한다.
- 저장소 하위 경로(`/fake-youtube-prop`)에서도 이미지와 설정 페이지 이동이 정상 동작해야 한다.
- `main` 및 배포 작업 브랜치에 변경이 올라오면 GitHub Actions가 정적 빌드와 Pages 배포를 수행한다.

## Vercel 배포
- Vercel에서 GitHub 저장소를 가져오면 Next.js 프로젝트로 자동 인식되어야 한다.
- 별도의 Build Command, Output Directory, 환경 변수 입력 없이 기본 설정으로 배포할 수 있어야 한다.
- Vercel용 표준 Next.js 빌드와 기존 Vinext 개발·검증, GitHub Pages 정적 export를 서로 독립적으로 유지한다.
- Vercel 배포에서도 루트 경로의 썸네일과 `/settings` 이동이 정상 동작해야 한다.

## 단일 HTML 배포물
- 인터넷 연결과 개발 서버 없이 더블클릭으로 실행되는 단일 `.html` 파일을 제공한다.
- CSS, JavaScript, 썸네일 이미지와 아이콘을 파일 내부에 모두 포함한다.
- 조회수 증가, 댓글 타이밍, 설명 창, 설정 화면, 전체화면, localStorage 저장 기능을 유지한다.
- 촬영 화면과 설정 화면은 한 문서 안에서 전환하며 새 파일이나 외부 라이브러리를 요청하지 않는다.
