# 조사 메모

## 제공 자료
- 참고 화면: 모바일 다크 테마 동영상 앱의 설명 패널.
- 썸네일: 교실에서 학생 세 명이 발표 팁을 소개하는 16:9 이미지.
- 극본 핵심: 조회수 97에서 시작해 새로고침 동작마다 1씩 증가하고, 100에서 부정적 댓글을 확인한다.

## 구현 판단
- 브라우저의 실제 OS 상태 표시줄은 웹페이지가 직접 수정할 수 없다.
- Fullscreen API로 브라우저 UI와 상태 표시줄을 최대한 숨기고, 필요할 때 앱 내부에 가짜 상태 표시줄을 렌더링한다.
- iPhone Safari는 일반 탭에서 Fullscreen API 지원이 제한될 수 있으므로 홈 화면 추가(PWA 스타일 실행) 또는 Android Chrome 사용이 가장 안정적이다.
- 촬영 소품이므로 네트워크·로그인·서버 저장은 필요하지 않다. 설정은 `localStorage`로 보존한다.
- 상표를 그대로 복제하기보다 촬영 프레임에서 익숙한 구조를 유지하는 가상의 `ViewTube` 앱으로 구성한다.

## GitHub Pages 배포 조사
- GitHub Pages는 서버 실행 없이 정적 산출물을 제공하므로 Next.js의 `output: "export"`가 필요하다.
- 프로젝트 사이트 주소는 저장소 이름이 하위 경로가 되므로 Pages 빌드에서만 `basePath: "/fake-youtube-prop"`를 적용한다.
- 앱 내부 `Link`는 `basePath`를 따르며, 일반 `<img>` 자산 경로는 빌드 환경의 base path를 직접 접두어로 사용한다.
- 기존 로컬/Vinext/Sites 빌드는 base path 없이 유지해 개발 서버와 기존 배포를 깨뜨리지 않는다.

## 단일 HTML 구현 조사
- 썸네일 WebP를 data URL로 인라인하면 `file://` 환경에서도 별도 자산 없이 표시된다.
- 외부 아이콘 패키지는 사용할 수 없으므로 촬영에 필요한 아이콘은 유니코드·CSS 도형·간단한 문자 기호로 대체한다.
- 같은 문서의 `film`/`settings` 뷰를 전환하면 전체화면 상태와 댓글 타이머를 유지할 수 있다.
- localStorage는 `file://`에서 브라우저별 제약이 있을 수 있으므로 저장 실패를 무시하고 현재 세션 기능은 유지한다.

## Vercel 가져오기 조사
- Vercel은 `next` 의존성과 `build` 스크립트를 기준으로 Next.js 프로젝트를 자동 감지한다.
- 기본 `build`를 `next build --webpack`으로 두면 Vercel 대시보드에서 별도 명령을 입력할 필요가 없다.
- 현재 테스트는 Vinext가 생성하는 `dist/index.html`을 검사하므로 Vinext 빌드는 `build:sites`로 분리하고 테스트가 이를 명시적으로 사용해야 한다.
- Pages 전용 환경 변수와 base path는 `build:pages`에만 적용되므로 Vercel 루트 배포와 충돌하지 않는다.

## 진행률 원 마커 잘림 조사
- 진행률 막대 높이는 4px, 원 마커 지름은 13px이며 마커 중심이 막대 중앙에 놓인다.
- 마커가 영상 하단보다 약 4.5px 돌출되지만 영상 컨테이너의 `overflow: hidden`이 돌출 부분을 잘랐다.
- 컨테이너의 돌출 렌더링을 허용하고 8px 하단 여백을 예약하면 4/8px 간격 체계를 유지하면서 원 전체와 다음 콘텐츠를 분리할 수 있다.

## 좋아요·싫어요 설정 조사
- 기존 화면은 좋아요 `12`와 싫어요 라벨을 JSX·단일 HTML에 하드코딩하고 있어 촬영 장면별 변경이 불가능하다.
- `likeCount`와 `dislikeCount`를 공용 설정 모델에 추가하고 0 이상의 정수로 정규화해야 한다.
- 기존 localStorage 값에는 새 필드가 없으므로 `Number.isFinite` 검사 실패 시 기본값으로 보완하면 저장 데이터 마이그레이션 없이 호환된다.

## 장면별 조회수 빠른 초기화 조사
- 기존 초기화 버튼은 사용자가 마지막으로 저장한 시작 숫자 한 곳으로만 돌아가 두 장면을 번갈아 촬영할 때 재입력이 필요했다.
- 극본의 고정 시작점인 45와 97을 명시적인 두 버튼으로 제공하면 현장에서 장면 전환과 재촬영 실수를 줄일 수 있다.
- 빠른 버튼은 `startCount`와 `viewCount`를 함께 갱신해야 이후 화면 복귀와 새로고침에서도 선택한 장면 기준이 유지된다.

## 기본 해시태그 학교급 전환
- 기본 문구만 변경하면 이미 localStorage에 저장된 기존 브라우저에는 `#중학생`이 계속 남는다.
- 과거 기본 해시태그 문자열과 정확히 일치하는 경우에만 새 기본값으로 치환하면 기존 기본값은 갱신하면서 사용자 맞춤값은 보존할 수 있다.
