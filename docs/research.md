# 조사 메모

## 제공 자료
- 참고 화면: 모바일 다크 테마 동영상 앱의 설명 패널.
- 썸네일: 교실에서 학생 세 명이 발표 팁을 소개하는 16:9 이미지.
- 극본 핵심: 조회수 97에서 시작해 새로고침 동작마다 1씩 증가하고, 100에서 부정적 댓글을 확인한다.

## 구현 판단
- 브라우저의 실제 OS 상태 표시줄은 웹페이지가 직접 수정할 수 없다.
- Fullscreen API로 브라우저 UI와 상태 표시줄을 최대한 숨기고, 필요할 때 앱 내부에 가짜 상태 표시줄을 렌더링한다.
- iPhone Safari는 일반 탭에서 Fullscreen API 지원이 제한될 수 있으므로 홈 화면 추가(PWA 스타일 실행) 또는 Android Chrome 사용이 가장 안정적이다.
- 촬영 소품이므로 네트워크·로그인·서버 저장은 필요하지 않다. 설정은 `localStorage`로 보존한다.
- 상표를 그대로 복제하기보다 촬영 프레임에서 익숙한 구조를 유지하는 가상의 `ViewTube` 앱으로 구성한다.
